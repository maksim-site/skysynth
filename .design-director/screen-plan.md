# Screen plan

## Shared page skeleton

1. Hero / physical product stage.
2. Compact proof ribbon using confirmed capabilities only.
3. Developments showroom with six real boards.
4. Competencies in large editorial sections, not a generic card grid.
5. Engineering process as a numbered technical ledger.
6. Materials / production / documentation proof only when supplied by the client.
7. Compact project inquiry and contacts.

## Responsive plan

- Desktop: 12-column grid, full-bleed product stage and restrained overlay copy.
- Tablet: 8-column grid; product remains the dominant half of the first viewport.
- Mobile: 4-column grid; one-board viewer with lower DPR, static ambient background and simplified particles.
